# Luciel 자기소개 사이트

음악과 그림을 좋아하는 Luciel을 소개하는 한국어 웹사이트입니다. 검정 바탕에 회색·흰색과 블루 포인트를 사용합니다. 자기소개와 작품을 별도 페이지로 보여 주며, 휴대전화와 컴퓨터 화면을 지원합니다. 실제 작품 이미지는 `public/`에 추가해 소개할 수 있습니다.

## 실행하기

Node.js 24 LTS를 설치한 뒤 프로젝트 폴더에서 실행합니다.

```sh
npm install
npm run dev
```

터미널에 표시되는 주소를 브라우저에서 엽니다. 개발 서버를 종료하려면 `Ctrl + C`를 누릅니다.

## 확인 및 배포용 빌드

```sh
npm run lint
npm run build
```

배포용 파일은 `dist/`에 생성됩니다.

## 주요 파일

- `src/App.jsx`: 홈, 자기소개, 작품 페이지의 내용과 이동 경로
- `src/App.css`: 페이지 디자인과 화면 크기별 배치
- `src/index.css`: 공통 색상과 기본 스타일
- `public/`: 그림 등 사이트에 넣을 이미지 파일

작품 이미지를 추가할 때는 파일을 `public/`에 넣고 작품 페이지에서 불러오면 됩니다.
